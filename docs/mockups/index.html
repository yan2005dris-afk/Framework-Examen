Pantallas del sistema

Treinta y seis pantallas estáticas que cubren el RF del IESS: registro y acceso (EF-11), formulario de 9 secciones (EF-12) y módulo de administración (EF-13). Cada archivo se abre solo, sin servidor, y cada estado real tiene su propio archivo.

Cómo leer este set

Los identificadores de archivo (06-03) son el prefijo del número de sección del RF. El mapa pantalla → historia de usuario → componente shadcn está en README.md.
